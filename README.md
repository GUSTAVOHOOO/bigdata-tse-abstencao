# Abstenção eleitoral no Brasil (TSE) – Etapa 1 de Big Data

Projeto da disciplina de Big Data que reúne os dados de perfil de comparecimento e abstenção divulgados pelo Tribunal Superior Eleitoral (TSE) para as eleições de 2018, 2020, 2022 e 2024. Os arquivos brutos são organizados em camadas (bronze, silver e gold), tratados com DuckDB, PyArrow e pandas, e analisados a partir de recortes por UF e município.
